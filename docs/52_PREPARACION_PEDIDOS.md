# Preparación física de pedidos — candidato
Solicitud del propietario: acceso inmediato a Preparado y reversión, sin abrir el acordeón. Amarillo = En preparación; azul = Preparado; verde = Completado. El botón incluye acción explícita y objetivo de 44 px. No se modifica el orden cronológico ni la lógica de entrega.
Preparación es metadato persistente separado de status active/completed/voided. RPC exclusiva de administradores activos, con bloqueo de fila y versión para impedir escrituras obsoletas. Auditoría RLS solo lectura para administradores. Una edición de composición reinicia la preparación y la versión; cierre y archivo conservan historial pero no permiten cambiar preparación. No se impone preparación como prerrequisito de pago o entrega. No afecta stock, saldo, enlaces, etiquetas ni reglas de cierre. Migración aditiva aplicada a Supabase, sin datos de prueba en remoto. Validar en PC/móvil y con otro administrador; mantener rama visual pendiente de aprobación del nuevo flujo.
